# Assembler CSS

## Purpose

Assembler CSS is a CSS library.

### Agenda

**Description**

this needs to be a very light-weight css library, it should have a terminal like aesthetic, having a 'hard-edged pixels' look, the kind of ui present in fallout 4 is similar to what I expect, but it should have configurable coloring, with both a light and dark mode

v0_01 will be the first alpha version
